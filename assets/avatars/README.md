# Agent avatars

Painterly portraits in a Disco Elysium style, sized for Discord webhook avatars
(512×512 PNG). Point an agent at one with `avatar_url` in `agents.yaml`:

```yaml
agents:
  journalist:
    channel_id: "..."
    avatar_url: "https://raw.githubusercontent.com/aSempruch/Claub/main/assets/avatars/khaki-trenchcoat.png"
```

Filenames describe **what the picture shows**, never what the agent does — the
avatar an agent uses shouldn't advertise its purpose to anyone browsing this
repo. Pick by look, not by role.
